H3 组织一次跨角色的计划复盘

本页内容
围绕同一组数据和结果讨论会前准备同一套复盘资料按角色提问组织一次小型复盘练习与参考解析让复盘留下长期价值延伸阅读

围绕同一组数据和结果讨论

计划员关心交期，数据人员关心来源，车间关心执行变化，伙伴关心配置与接口。复盘需要让大家围绕同一份输入、配置和结果提出问题，而不是各自展示不同版本的截图。

本课用于企业学习小组或伙伴培训。可使用已发表的冲压、注塑案例，也可使用经确认允许分享的本地运行记录。

会前准备同一套复盘资料

内容 应包含什么
场景说明 本次决定、对象、周期与承诺
输入摘要 版本、单位、关键关系和检查结果
配置差异 基线与调整的变化项
运行记录 状态、参数、动作与结果来源
结果对照 实际指标、目标统计量、对象明细
待讨论问题 未解释变化与待批准措施

只给出支持讨论的信息，分享前确认数据范围。截图用于帮助定位，表格与记录用于检查数值。

按角色提问

计划员解释为什么选择这些目标，以及哪些承诺必须保持。数据人员解释定义和更新时点，指出未知或暂估内容。车间人员检查变动任务能否执行、准备是否足够。技术伙伴解释实际调用与生效规则，区分配置、候选与执行结果。

每个人都应能提出至少一个可能改变结论的新事实。例如设备维护时窗与模型假设不同、订单已经取消、已冻结任务尚未被标识。这些发现比重复“结果看起来不错”更能推动改进。

组织一次小型复盘

  1. 由主持人复述问题及比较条件。
  2. 由数据人员确认输入和单位。
  3. 由运行负责人说明动作、状态与配置差异。
  4. 共同查看总体指标和一个关键对象的明细。
  5. 讨论可采用内容、代价、未决事项与责任人。
  6. 形成下一轮只改变哪些条件的计划。

讨论时把“事实、解释、建议、决定”分别记录。建议只有经责任人确认并执行后，才可在后续记录中写成已采取措施。

练习与参考解析

以注塑记录为例，请学习者说明为什么不能从14.9与66.4计算改善比例；再请另一位解释为什么容器容量不是设备产能。两项回答都应指向定义与配置，而非只凭词语。

最后生成三项成果：一条已确认结论、一项需要补充的检查、一项明确负责人的后续工作。若大家能够用自己的话复述数据、取舍和执行条件，教学已经从“看过功能”进入“能够共同使用”的阶段。

让复盘留下长期价值

将新的字段解释、检查规则和已确认案例写回团队知识材料。后续相似问题可以复用原有结构，新增事实则进入下一次更新。企业的决策能力由这样连续的使用、解释和修正逐步形成。
