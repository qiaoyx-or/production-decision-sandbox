# Guide illustrations

These assets are reused from the DecisioWorks product and solution whitepapers.

- `brand-hero.png`: original DecisioWorks landscape brand visual, shared by both languages.
- `architecture-zh.png`, `capability-chain-zh.png`, `adoption-zh.png`: Chinese whitepaper illustrations.
- `architecture-en.png`, `capability-chain-en.png`, `adoption-en.png`: corresponding English illustrations extracted from the published English whitepaper source documents.

Image files are unchanged. Layout sizing is handled in CSS. Diagram labels also have readable HTML explanations in the guides, with links to the full-size illustrations.
