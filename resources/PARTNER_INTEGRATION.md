# DecisioWorks 伙伴集成指南

## 一条可复核的接入路径

业务问题确认 → 数据导出 → 标准接口映射 → 结构关系诊断 → 配方配置 → 本地授权运行 → 结果解释 → 业务确认与反馈。

制造企业提供真实业务语义、目标优先级和结果验收意见；咨询伙伴梳理问题与取舍；软件及集成伙伴负责数据映射、调用方式和界面衔接；DecisioWorks 提供数据处理、能力编排、受控求解与结果分析的基础能力。

## 首个场景的交付物

| 交付物 | 应明确的内容 | 复核人 |
| --- | --- | --- |
| 场景说明 | 决策周期、对象范围、当前难题、可调整范围 | 业务负责人 |
| 数据映射 | 原始字段、标准字段、单位、时间坐标与引用关系 | 数据与业务人员 |
| 配方 | 标准动作、能力、参数、规则来源 | 实施人员 |
| 运行记录 | 数据版本、输入哈希、实际参数、状态和耗时 | 技术人员 |
| 结果对比 | 实物数量、负荷、交付影响、切换与业务解释 | 计划人员 |
| 验收意见 | 接受条件、未满足项、后续调整与责任归属 | 业务负责人 |

## 调用边界

本地工作台通过选定运行目录的现有数据载入器、配方加载器、标准执行引擎和参数校验接口完成调用。它不重写求解器或授权逻辑。

首版支持两个标准样例与六个固定标准动作。维护窗口、冻结任务、共享资源及偏差联动等案例提供接入思路；实际接入需要在对应 DecisioWorks 能力、模型与配方上完成配置和验证。

## 从试点到持续使用

每次扩展优先保持数据版本、规则来源、运行配方和结果证据可追溯。企业业务变化时，分别调整数据、偏好、控制规则或能力组合，再使用同一组验收条件进行回归。

研究版与商业版的使用范围、源码使用条款及授权等级，以所使用的 DecisioWorks 发行文件为准。公开参考代码的提供与软件的商业授权分别遵循对应发行许可。
