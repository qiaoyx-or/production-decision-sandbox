# Production Decision Sandbox Web

基于 DecisioWorks 的生产决策沙盘工作台第一版 React/Vite 原型。

## 功能范围

- 数据集与验证场景切换
- 交期权重、维护避让参数交互
- APS 标准对象模型表
- 能力编排链路图
- 资源负载与方案对比图
- 排程时间轴
- frePPLe / SuperAPS / OpenMES 参考取舍

## 运行

```bash
cd /home/qiaoyx/workspace/production-decision-sandbox/apps/web
npm install
npm run dev -- --port 5178
```
