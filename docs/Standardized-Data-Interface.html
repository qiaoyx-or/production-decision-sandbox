把订单、工艺、产能、物料和时间关系转化为可计算业务结构。

适用于 DecisioWorks v1.4.0

标准化数据接口

标准化数据接口让业务事实进入可计算结构，字段映射只是其中的基础步骤。

核心对象

订单、制品、工艺路线、工序、工作中心、产能、日历、班制、设备维护、物料、工序级 BOM、库存、齐套信息和计划结果，通过明确主键、时间坐标和关联关系组成业务链。

四条关键关系

  1. 时间链：交期、产能、齐套和结果使用一致时间坐标。
  2. 制品链：订单、路线、库存和属性指向同一制品语义。
  3. 工艺产能链：制品经路线和工序映射到可执行资源。
  4. 物料齐套链：物料条件绑定到具体工序和计划层级。

接口模板保存在场景 data.db 中。字段齐全只是起点，关系闭合、语义一致和约束可执行才是进入求解链路的条件。

设计理念：字段齐全只是起点

APS 数据接入需要证明时间、制品、工艺产能和物料齐套关系能够闭合。只有业务对象、关联关系、单位和约束语义一致，数据才真正进入生产决策。

典型应用

  • 没有 ERP、MES 时，以 data.db 作为标准数据接口模板快速组织场景；
  • 已有 ERP、MES 时，将来源数据映射为统一业务语义，降低系统集成牵制；
  • 表达班制、维护、共享资源、批量、出件率和工序级 BOM；
  • 为主生产计划、作业排程、齐套判断和 AI Agent 接入提供共同输入。

差异化

常见接口以“字段能传递”为验收目标；DecisioWorks 进一步区分结构可读、业务关系闭合和求解就绪。标准接口因此既是数据入口，也是业务建模和约束进入模型的第一步。
