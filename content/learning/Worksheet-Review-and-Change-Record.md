# Worksheet: Review and Change Record

[中文](Worksheet-Review-and-Change-Record-zh-CN.md) · [Learning Center](Learning-Center.md)

## Review Record
| Item | Record |
|---|---|
| Scenario and run identity | Evidence under discussion |
| Confirmed facts | Inputs, configuration, status and result sources |
| Business interpretation | Measures that improved, stayed the same or worsened, and the objects affected |
| Open questions | Information or checks still needed |
| Decision | Adopt, adjust, wait or reassess |
| Owner and timing | Responsibility and review date |
| Next changes | Data, rules or configuration to modify |
| Acceptance | How completion will be confirmed |

## Cross-Functional Confirmation
Planners explain commitments and objectives, data specialists explain definitions and updates, operators assess feasibility, and technical partners explain enforcement. Preserve reasons and scope for every change.

## Next Review
Compare expectations with observations. Distinguish data changes, configuration differences, execution conditions and model fit. Update shared definitions and checks without rewriting the original run facts.
