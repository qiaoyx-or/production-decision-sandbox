# Worksheet: Scenario and Decision Task

[中文](Worksheet-Scenario-Brief-zh-CN.md) · [Learning Center](Learning-Center.md)

## Purpose
Describe a production problem clearly enough to prepare data, select a capability and inspect results. Have business and technical participants confirm it before execution, then use it to guide data preparation and result comparison.

| Item | Record |
|---|---|
| Decision | Quantities, timing, sequence or resources |
| Scope | Orders, products, operations, work centers and period |
| Data source/version | Source, cutoff and consistent identity |
| Quantity/time units | Source units and conversions |
| Fixed conditions | Commitments, started or frozen work |
| Adjustable conditions | Supported objectives, resources or rules |
| Readiness | Materials, shifts, maintenance and shared resources |
| Baseline | Current configuration or confirmed plan |
| Measures | Definition, denominator, unit and granularity |
| Owners | Responsibility for data, objectives, measures and approval |

## Use
The requester defines the task and commitments. A data specialist checks units and relationships. The operator confirms that the selected capability accepts the inputs. Update the version when scope changes.

## Completion Check
Another person can identify the decision, fixed conditions and result checks. Resolve ambiguous fields before running.
