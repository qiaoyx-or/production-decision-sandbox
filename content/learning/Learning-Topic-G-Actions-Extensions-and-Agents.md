# G Connect Applications and AI Agents through Standard Actions

[中文](Learning-Topic-G-Actions-Extensions-and-Agents-zh-CN.md) · [Learning Center](Learning-Center.md)

Read recipes, choose extension points and write reviewable Agent tasks. Explicit inputs, outputs and statuses let automation and human operation share capabilities.

## Preparation and Outcomes
Start with [B1's data mapping](Learning-B1-Business-Tables-to-Computable-Objects.md), [C2's objective interpretation](Learning-C2-Explain-Objective-Tradeoffs.md) and [F1's component responsibilities](Learning-F1-Place-Changes-in-the-Right-Layer.md). G1 is a recipe-reading lesson, G2 assumes Python development experience, and G3 starts with a natural-language task.

Discuss the excerpts and prompts offline. Execution uses the complete release examples, dependencies and valid authorization; extension work also needs an editable calling layer and a test environment. Outcomes are a configuration diff, an extension design with tests, and an Agent task with review records.

1. [Read and Modify a Capability Orchestration Recipe](Learning-G1-Read-and-Modify-a-Recipe.md)
2. [Extend a Capability with a Clear Calling Interface](Learning-G2-Extend-a-Capability.md)
3. [Write an AI Agent Task That Can Be Reviewed](Learning-G3-Write-an-Agent-Task.md)

Read the three lessons in order. Attempt each exercise before checking the suggested answer, and use the worksheets to record conditions, results and open questions.
