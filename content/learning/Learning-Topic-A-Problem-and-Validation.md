# A From a Production Problem to a Testable Decision

[中文](Learning-Topic-A-Problem-and-Validation-zh-CN.md) · [Learning Center](Learning-Center.md)

Define the scope, commitments and adjustable conditions before comparing plans. These lessons develop a scenario brief, a validation design and a comparable result record.

## Preparation and Outcomes
No software installation is needed. Choose a familiar production question, or use A1's teaching workshop and A2's hand-calculated example.

Finish with a one-page scenario brief and a plan-comparison table that identify the decision, fixed conditions, permitted changes and evaluation basis.

1. [Define a Decision Task from a Delivery Problem](Learning-A1-Define-a-Decision-Task.md)
2. [Validate First: Design a Useful Planning Comparison](Learning-A2-Design-a-Useful-Planning-Comparison.md)
3. [Compare Two Plans on the Same Basis](Learning-A3-Compare-Plans-on-the-Same-Basis.md)

Read the three lessons in order. Attempt each exercise before checking the suggested answer, and use the worksheets to record conditions, results and open questions.
