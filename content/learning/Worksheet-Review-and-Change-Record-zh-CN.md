# 工作表：复盘与持续改进记录

[English](Worksheet-Review-and-Change-Record.md) · [学习中心](Learning-Center-zh-CN.md)

## 复盘记录
| 项目 | 填写内容 |
|---|---|
| 场景及运行标识 | 本次讨论对应哪份记录 |
| 已确认事实 | 输入、配置、状态与结果来源 |
| 业务解释 | 哪些指标改善、不变或变差，影响哪些对象 |
| 未决问题 | 需要补充哪些信息或检查 |
| 决定 | 采用、调整、等待或重新评估 |
| 负责人及时间 | 谁处理，何时检查 |
| 后续变化 | 修改哪些数据、规则或配置 |
| 通过条件 | 怎样确认问题已处理 |

## 跨角色确认
计划人员说明承诺与目标，数据人员说明定义与更新，现场人员说明可执行性，技术伙伴说明生效路径。每项变化保留原因与影响范围。

## 下次复盘
将预期与实际观察对照。未达到预期时区分数据变化、配置差异、执行条件与模型适用性。把新确认的定义或检查更新到团队材料中，不改写原始运行事实。
